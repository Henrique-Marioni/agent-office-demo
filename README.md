# Agent Office — demonstração

Demonstração **visual** do Agent Office, um escritório virtual que mostra agentes de IA (Claude Code) trabalhando.

- Tudo aqui é **fictício**: a equipe, as tarefas, os arquivos e os erros são inventados e rodam em loop no próprio navegador.
- Não há servidor, banco de dados nem conexão com nenhum projeto real.
- O código-fonte do projeto fica em um repositório privado; este repositório contém só o site já montado.

Abra: https://henrique-marioni.github.io/agent-office-demo/
